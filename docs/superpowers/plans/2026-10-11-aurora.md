# Aurora and Space Weather Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An `aurora(place)` chat tool plus a channel announcer for major geomagnetic storms (NOAA G3+ watches and sustained Bz ≤ −10 nT), both reporting darkness and cloud cover.

**Architecture:** A new pure-function module `spaceweather.py` (parse, classify, render) with a small fixed-host fetch layer, modelled on `statuspage.py`. `plugin.py` gets a tool builder wired like `_build_meme_tool` and an executor-submitted, self-rescheduling poll wired like `_schedule_status_poll` / `_enqueue_status_poll` / `_run_status_poll`.

**Tech Stack:** Python 3.14, Limnoria, stdlib `urllib` + `json` + `zoneinfo`, pytest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-11-aurora-design.md`

## Global Constraints

- No new dependencies; solar position is computed in-module.
- Only rows with `active: true` from the RTSW feeds are used, deduplicated by UTC minute.
- Bz threshold default `-10` nT, window default `3` h, minimum watch level default `3` (G3).
- The Bz rule is a heuristic for "sustained storm-driving conditions", not a guarantee of a storm; user-facing text says "storm conditions".
- Dark means sun altitude < −12°.
- Lead time minutes = `round(1.5e6 / latest_speed_kms / 60)`.
- Fetches go only to `services.swpc.noaa.gov`, `geocoding-api.open-meteo.com`, `api.open-meteo.com` (constants), with redirects refused like `statuspage._default_opener_factory`.
- Announcement lines are deterministic templates; no LLM rewrite.
- Announcements never name places from user memories, only `auroraAnnouncePlaces`.
- No backwards compatibility shims (one deployment).
- Before every commit: `make check` green (lint, format, ty, syntax, tests, 93% coverage).
- Commit on `main`; **do not push** (push = prod deploy). The human pushes.

## Review Focus

1. **Southern-hemisphere place** ("aurora in Hobart"): "poleward" means south; `ovation_at` searches toward the place's own pole. Test in Task 2.
2. **Negative longitudes** (all of North America): the OVATION grid uses 0..359; `-79.4` maps to `281`. Test in Task 2.
3. **Null or junk fields in RTSW rows** (`bz_gsm: null`, NaN, `proton_speed <= 0`, duplicate minutes): a missing minute, never 0, never double-counted. Test in Task 1.
4. **Superseding watches**: NOAA re-issues watches every few hours; the newest issuance replaces older ones wholesale, and a channel hears only a level rise for a date. Test in Tasks 2 and 5.
5. **Polar night / midnight sun** (Tromsø in December or June): `dark_window` returns "dark all night" or "never dark" instead of raising or looping. Test in Task 2.

**Interfaces:**
- Produces:
  - `class InvalidPayload(ValueError)`
  - `@dataclass(frozen=True) class Sample: ts: datetime; bz: float | None; bt: float | None; speed: float | None`
  - `parse_rtsw(mag: list[dict], wind: list[dict]) -> list[Sample]` — active rows only, one `Sample` per UTC minute (later row wins), oldest first. Non-finite numbers and `speed <= 0` become `None`. Raises `InvalidPayload` if either payload is not a list of dicts.
  - `storm_conditions(samples, *, threshold_nt: float, hours: float, now: datetime) -> bool` — False if the newest sample is more than 15 min old. Otherwise True when distinct minutes with `bz` in the trailing window ≥ 80% of `hours*60` **and** ≥ 80% of those have `bz <= threshold_nt`.
  - `trailing_mean_bz(samples, *, now: datetime, minutes: int = 30, min_points: int = 24) -> float | None` — `None` when fewer than `min_points` minutes have data.
  - `@dataclass(frozen=True) class Episode: start: datetime; min_bz: float; latest_speed: float | None; mean_ey: float | None; lead_minutes: int | None`
  - `advance_episode(current: Episode | None, samples, *, threshold_nt: float, hours: float, now: datetime) -> Episode | None`

`advance_episode` lifecycle (not determined by the signature):
```
if current is None:
    if not storm_conditions(...): return None
    start = walk back from now while trailing_mean_bz(at t) is not None and <= -5; start = earliest such t
    return Episode(start, ...stats over [start, now])
mean = trailing_mean_bz(samples, now=now)
if mean is not None and mean > -5: return None            # ended
return Episode(current.start, min(current.min_bz, window min), ...)  # start is latched; gaps keep it alive
ey = speed * -bz / 1000 for minutes with bz < 0 and speed present (mV/m), averaged over [start, now] within the feed
latest_speed = mean speed over the last 30 min
```

**Interfaces:**

**Interfaces:**

- Produces:
  - Config: `spaceWeatherAnnounce` (channel, `Boolean(False)`), `spaceWeatherPlaces` (channel, `SpaceSeparatedListOfStrings([])`; `_` stands for a space, e.g. `Sault_Ste._Marie`), `spaceWeatherMinWatchLevel` (global, `NonNegativeInteger(3)`; clamp to 1..5).
  - State (all fields `field(default_factory=…)`):
    ```python
    @dataclass
    class SwState:
        watches_seeded: bool = False
        episode_seeded: bool = False
        episode: Episode | None = None
        announced_levels: dict[str, dict[date, int]]   # channel -> date -> level told
        episode_acked: dict[str, datetime]             # channel -> episode.start told
    ```
  - `watch_news(levels: dict[date, int], told: dict[date, int], *, min_level: int) -> dict[date, int]` — dates with `level >= min_level` and `level > told.get(date, 0)`.
  - `render_watch_line(levels: dict[date, int], clouds: dict[str, int | None]) -> str` and `render_storm_line(episode: Episode, *, now: datetime, clouds: dict[str, int | None], direction: str) -> str` — exact templates:
    - `🌌 NOAA G{max} storm watch for {Oct 12–13}. Clouds tonight: {Place pct%, ...}.`
    - `🌌 Aurora storm conditions: Bz {min_bz:.0f} nT for {h}h{mm:02d}m at {latest_speed:.0f} km/s (~{lead} min to Earth). Look {direction}. Clouds now: {Place pct%, ...}.`
    - Empty `clouds` → the `Clouds…` sentence is omitted; a `None` value renders `Place ?`. `direction` is `"south"` only when every configured place has `lat < 0`.
  - `LLM._schedule_spaceweather_poll`, `LLM._enqueue_spaceweather_poll`, `LLM._run_spaceweather_poll` — copies of the status trio: event name `llm_spaceweather_poll`, `_SPACEWEATHER_POLL_INTERVAL = 300`, `_sw_poll_inflight = threading.Event()`, submit via `self._llm_executor.submit("spaceweather_poll", …)`, re-arm in done-callbacks and on submit failure, no-op when `self._llm_executor.closing`. Pass budget `_SPACEWEATHER_PASS_BUDGET = 60` s: stop sending when exceeded.
  - `LLM._deliver_spaceweather_line(self, channel: str, line: str) -> bool` — `_irc_for_channel`, `_safe_queue(irc, _safe_privmsg(channel, line))`.

Poll flow:
1. Fetch mag+wind and alerts independently; a failed feed logs at info and skips only its half of the pass.
2. Watches (alerts read OK): `levels = effective_levels(...)`. If `not watches_seeded`: set every announcing channel's `announced_levels` to `levels`, set `watches_seeded`, stop. Otherwise per announcing channel (a channel seen for the first time is seeded silently): `news = watch_news(levels, told, min_level)`; if any, send `render_watch_line(news, clouds)` with clouds = mean cloud over each place's `dark_window` for the first date in `news`; on successful queue, `told.update(news)`.
3. Episode (RTSW read OK): `state.episode = advance_episode(state.episode, …)`. If `not episode_seeded`: ack every announcing channel for a running episode, set `episode_seeded`, stop. If no episode: clear `episode_acked`. Otherwise per announcing channel with `episode_acked.get(ch) != episode.start` (a channel seen for the first time mid-episode is acked silently): if it has no places, or any place `is_dark(now)`, send `render_storm_line` with mean cloud over the next 3 h; on successful queue, ack.
