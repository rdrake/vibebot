# Aurora and Space Weather Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An `aurora(place)` chat tool plus a channel announcer for major geomagnetic storms (NOAA G3+ watches and sustained Bz ≤ −10 nT), both reporting darkness and cloud cover.

**Architecture:** A new pure-function module `spaceweather.py` (parse, classify, render) with a small fixed-host fetch layer, modelled on `statuspage.py`. `plugin.py` gets a tool builder wired like `_build_meme_tool` and a self-rescheduling poll wired like `_schedule_status_poll` / `_run_status_poll`.

**Tech Stack:** Python 3.14, Limnoria, stdlib `urllib` + `json`, pytest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-11-aurora-design.md`

## Global Constraints

- No new dependencies; solar position is computed in-module.
- Only rows with `active: true` from the RTSW feeds are used.
- Bz threshold default `-10` nT, window default `3` h, minimum watch level default `3` (G3).
- Dark means sun altitude < −12°.
- Lead time = `1.5e6 / speed_kms` seconds, rendered in minutes.
- Fetches go only to `services.swpc.noaa.gov`, `geocoding-api.open-meteo.com`, `api.open-meteo.com` (constants, never user-supplied hosts).
- Announcement lines are deterministic templates; no LLM rewrite.
- Announcements never name places from user memories, only `spaceWeatherPlaces`.
- No backwards compatibility shims (one deployment).
- Coverage floor 93% (`make test`).
- Commit on `main`; **do not push** (push = prod deploy). The human pushes.

## Review Focus

1. **Southern-hemisphere place** ("aurora in Hobart"): "poleward" means south; `ovation_at` must search toward the place's own pole. Test in Task 2.
2. **Negative longitudes** (all of North America): the OVATION grid uses 0..359; `-78.9` must map to `281`. Test in Task 2.
3. **Null fields in RTSW rows** (`bz_gsm: null`, `proton_speed: null` occur in active rows): treat as a missing minute, never as 0. Test in Task 1.
4. **Superseding watches** ("THIS SUPERSEDES ANY/ALL PRIOR WATCHES"): NOAA re-issues watches with new serials every few hours; only announce when the level for some date rises above what was already announced. Test in Task 5.
5. **Polar night / midnight sun** (a place in Tromsø in December or June): `dark_window` returns "dark all night" or "never dark" instead of raising or looping. Test in Task 2.

### Task 1: Solar-wind samples and the Bz episode rule

**Files:**
- Create: `plugins/llm/src/llm/spaceweather.py`

- Create: `plugins/llm/tests/fixtures/spaceweather/rtsw_mag_1m.json`, `rtsw_wind_1m.json` (capture live with `curl`; trim to ~300 rows keeping all three `source` values)

**Interfaces:**
- Produces:
  - `@dataclass(frozen=True) class Sample: ts: datetime; bz: float | None; bt: float | None; speed: float | None`
  - `parse_rtsw(mag: list[dict], wind: list[dict]) -> list[Sample]` — active rows only, joined on `time_tag` (minute), oldest first. Raises `InvalidPayload` (new `ValueError` subclass in this module) if either payload is not a list of dicts.
  - `@dataclass(frozen=True) class Episode: start: datetime; minutes: int; min_bz: float; mean_speed: float | None; mean_ey: float | None; lead_minutes: int | None`
  - `bz_episode(samples: list[Sample], *, threshold_nt: float, hours: float, now: datetime) -> Episode | None`

`bz_episode` algorithm (not determined by the signature):
```
window = samples with now - hours <= ts <= now
have   = [s for s in window if s.bz is not None]
qualifies if len(have) >= 0.8 * hours*60 and count(bz <= threshold) >= 0.8 * len(have)
if not qualifies: return None
start  = walk back from now through samples while the trailing-30-min mean bz <= -5; first minute of that run
ey     = speed * -bz / 1000 for minutes with bz < 0 and speed present (mV/m)
lead   = round(1.5e6 / mean_speed / 60) if mean_speed else None   # speed = mean over last 30 min
```

### Task 2: Watches, darkness, and the OVATION lookup

**Files:**
- Modify: `plugins/llm/src/llm/spaceweather.py`

**Interfaces:**
- Produces:
  - `@dataclass(frozen=True) class Watch: serial: int; issued: datetime; levels: dict[date, int]` (0 = below G1)
  - `parse_watches(alerts: list[dict]) -> list[Watch]` — messages whose `message` contains `WATCH: Geomagnetic Storm Category G`; skip any containing `CANCEL`. Parse `Serial Number:`, `Issue Time: YYYY Mon DD HHMM UTC`, and each `Mon DD:  G<n>` / `Mon DD:  None` pair in the "Highest Storm Level Predicted by Day" line. Year comes from the issue time; a December issue with a January day rolls the year forward.
  - `sun_altitude(lat: float, lon: float, when: datetime) -> float` (degrees; NOAA solar-position equations)
  - `dark_window(lat: float, lon: float, day: date) -> tuple[datetime | None, datetime | None]` — first minute after local noon of `day` where altitude < −12°, and the first minute after that where it rises above; 10-minute scan then refine to the minute. `(None, None)` = never dark; `(start, None)` = dark through the next noon.
  - `is_dark(lat: float, lon: float, when: datetime) -> bool`
  - `ovation_at(grid: dict, lat: float, lon: float) -> dict` → `{"overhead_pct", "poleward_max_pct", "poleward_max_lat", "forecast_time"}`; lon normalised with `% 360`; lat rounded; poleward = toward `+90` for `lat >= 0` else `-90`, up to 10°.

### Task 5: Storm announcer

**Files:**
- Modify: `plugins/llm/src/llm/spaceweather.py` (state + classify + render)
- Modify: `plugins/llm/src/llm/config.py`, `plugins/llm/src/llm/plugin.py` (poll schedule next to `_schedule_status_poll`; teardown next to `schedule.removeEvent("llm_status_poll")` at ~1171 and ~1252)
- Create: `plugins/llm/tests/test_spaceweather_announce.py`
- Modify: `docs/guide/operator/configuration.md`, `docs/guide/user/aurora.md`

**Interfaces:**
- Consumes: Tasks 1–3.
- Produces:
  - Config: `spaceWeatherAnnounce` (channel, `Boolean(False)`), `spaceWeatherPlaces` (channel, `SpaceSeparatedListOfStrings([])`; multi-word names use `_` for spaces, e.g. `St._John's`), `spaceWeatherMinWatchLevel` (global, `NonNegativeInteger(3)`).
  - `@dataclass(frozen=True) class SwState: seeded: bool = False; announced_levels: dict[date, int]; announced_episode: datetime | None = None; dark_announced: frozenset[str] = frozenset()` — `dark_announced` = channels told about the current episode.
  - `classify_watches(state, watches, *, min_level) -> tuple[list[Watch], SwState]` — cold start (`seeded False`) records every current watch's levels and returns `[]`. Otherwise a watch is new if any date has `level >= min_level` and `level > announced_levels.get(date, 0)`.
  - `classify_episode(state, episode: Episode | None) -> SwState` — `None` clears `announced_episode` and `dark_announced`; a new `episode.start` resets `dark_announced`. On cold start an already-running episode is seeded as announced to every channel (`dark_announced` = sentinel `{"*"}`).
  - `render_watch_line(watch, clouds: dict[str, int | None]) -> str` and `render_storm_line(episode, clouds: dict[str, int | None]) -> str` — exact templates:
    - `🌌 NOAA G{max} storm watch for {Mon DD–DD}. Clouds tonight: {Place pct%, ...}.`
    - `🌌 Major storm underway: Bz {min_bz:.0f} nT for {h}h{mm}m at {speed:.0f} km/s (~{lead} min to Earth). Look north. Clouds now: {Place pct%, ...}.`
    - Missing clouds → the `Clouds…` clause is omitted; a place with `None` renders `Place ?`.
  - `LLM._run_spaceweather_poll(self) -> None`, `LLM._schedule_spaceweather_poll(self) -> None` (event name `llm_spaceweather_poll`, interval `_SPACEWEATHER_POLL_INTERVAL = 300`), `LLM._deliver_spaceweather_line(self, channel: str, line: str) -> bool` (via `self._irc_for_channel`, `self._safe_queue`, `self._safe_privmsg`, same as `_deliver_status_line`).

Poll flow: fetch mag+wind+alerts (each failure logged at info, rest of pass continues) → `classify_watches` → for each new watch, every channel with `spaceWeatherAnnounce` gets `render_watch_line` with mean cloud over each place's dark window on the watch's first date at `level >= min_level` → `classify_episode` → for each announcing channel not in `dark_announced`, if any of its places `is_dark(now)`, send `render_storm_line` with next-3 h mean cloud and add the channel. A channel with no places is treated as always dark and gets no cloud clause. Geocoded places cached in `self._sw_places: dict[str, Place | None]` for the process lifetime. Mark announced only after a successful queue.
